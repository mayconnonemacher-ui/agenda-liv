# Agenda de entregas e montagem — Condomínio LIV

Página de consulta dos condôminos e de edição do síndico e da engenheira da construtora.

- Página: `index.html` (ramo `main`), publicada pelo GitHub Pages.
- Dados: `agenda.json` no ramo `dados`. A página lê e grava esse arquivo; não edite à mão.
- Edição: botão "Área do síndico" na página, com um token do GitHub restrito a este repositório (permissão Contents: Read and write).
